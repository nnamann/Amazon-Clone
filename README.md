# Amazon Clone

A responsive, multi-page **Amazon e-commerce website clone** built using **HTML, CSS, and Vanilla JavaScript**.

This project recreates the core shopping experience of Amazon, including product browsing, search, cart management, checkout, order history, and package tracking. It was originally developed as a learning project while following the SuperSimpleDev JavaScript course and was extended with additional functionality such as **search autocomplete**.

---

## Features

### Product Store

* Amazon-inspired homepage and product listing interface
* Product cards with images, ratings, prices, and delivery information
* Responsive layout for different screen sizes
* Interactive navigation and UI components

### Search

* Product search functionality
* **Search autocomplete** for faster product discovery
* Dynamic search suggestions based on available products

### Shopping Cart

* Add products to cart
* Increase or decrease product quantity
* Remove products from cart
* Dynamic cart quantity and pricing
* Persistent cart data using browser storage

### Checkout

* Dedicated checkout page
* Product and order summary
* Delivery information
* Payment section
* Dynamic order totals

### Orders

* Dedicated orders page
* View previously placed orders
* Order details and product information
* Order history maintained across pages

### Order Tracking

* Dedicated package tracking page
* View delivery progress
* Track individual orders and products

## Getting Started

```bash
# 1. Clone the repository
git clone https://github.com/nnamann/Amazon-Clone.git

# 2. Navigate to the project
cd Amazon-Clone
```

This project runs on plain HTML, CSS, and JavaScript, so it can be opened directly in a browser.

For the best development experience, open `amazon.html` in **VS Code with the Live Server extension**.
